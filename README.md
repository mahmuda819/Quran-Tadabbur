# Quran Tadabbur

Ek bilkul simple zaati Quran Tadabbur notes website.

## Kaise istemal karein
1. `index.html` browser mein kholte hi website chalegi.
2. Surah ke card par click karke ayat ke notes likhein.
3. `＋ Nayi ayat ka note shamil karein` se zarurat ke mutabiq ayat add kar sakte hain.
4. `＋ Nayi Surah` se nayi Surah/card add kar sakte hain.
5. Notes browser ke Local Storage mein save hote hain, is liye isi browser mein dobara kholne par notes rahenge.

## Files
- `index.html` — website ka main page
- `style.css` — design
- `script.js` — Surah, ayat aur notes ki functionality

## Zaroori baat
Yeh website filhal Local Storage par mabni hai. Doosre device ya browser mein wahi notes automatically nahi jayenge.


Updated: The home screen now contains only the canonical 114 Qur'an Surahs. Custom/new Surah cards have been removed. Existing notes for Surahs 1-114 are preserved when localStorage is present.
